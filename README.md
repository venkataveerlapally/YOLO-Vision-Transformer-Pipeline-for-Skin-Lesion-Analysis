# Skin Lesion Detection and Classification (YOLO + Vision Transformer)

This repository contains a complete end-to-end pipeline for **automated skin lesion detection and classification** using:

- **YOLO** for lesion detection  
- **Vision Transformer (ViT)** for classification  
- **HAM10000 dermatoscopic dataset**  

The goal is to detect a lesion in an input image and classify it into one of the dermatological diagnostic categories.

---

```text

```

# Vision Transformer (ViT)

### Train ViT

```bash
python train_vit.py --config vit_config.json
```

Saves trained weights to:

```text
vit_model/vit_weights.pth
```

---

### Test ViT

```bash
python test_vit.py --config vit_config.json --checkpoint vit_model/vit_weights.pth
```

---

# YOLO Detection

Place YOLO weights in:

```text
yolo_model/best.pt
```

### Run YOLO Detection

```bash
python detect.py --weights yolo_model/best.pt --source dataset/combined_images
```

---

# Full Pipeline (YOLO → ViT)

```bash
python detect_and_classify.py --image path/to/image.jpg
```

This script:
1. Detects lesion with YOLO  
2. Crops the detected region  
3. Classifies lesion using ViT  

---

# Dataset Preparation Scripts

### Combine Images
```bash
python combine_images.py
```

### Split Dataset
```bash
python split_dataset.py --metadata dataset/HAM10000_metadata.csv --images dataset/combined_images --out dataset/
```

### Prepare YOLO Labels (Optional)
```bash
python prepare_yolo_labels.py
```
